================================================================================
EXPECTED RESPONSE (ASYNC)
================================================================================

BAP will receive IMMEDIATE ACK:
{
  "message": {
    "ack": {
      "status": "ACK"
    }
  }
}

Then BPP will POST callback to: bap_uri/on_search with catalog data

================================================================================
CONTEXT FIELDS EXPLANATION
================================================================================

Required Fields:
- domain: "agriculture:oan" (for OAN catalog registry)
- country: ISO country code (e.g., "IND")
- city: City name
- action: "search"
- core_version: Beckn version (e.g., "1.1.0")
- bap_id: Unique BAP identifier
- bap_uri: BAP callback URL (BPP will POST to bap_uri/on_search)
- transaction_id: Unique transaction UUID (persist across search/select/init/confirm)
- message_id: Unique message UUID (new for each request)
- timestamp: ISO 8601 timestamp

Optional Intent Fields:
- item.descriptor.name: Search query (product name, category, provider)
- If empty or not provided, returns all active products

================================================================================
IMPORTANT NOTES
================================================================================

1. Domain: Use "agriculture:oan" for OAN Catalog Registry
2. bap_uri: Must be accessible from BPP for callback
3. transaction_id: Should be same for entire transaction flow
4. message_id: Generate new UUID for each message
5. Async Response: BAP receives ACK immediately, then callback with results
6. Search Query: Case-insensitive, matches product name, category, provider
