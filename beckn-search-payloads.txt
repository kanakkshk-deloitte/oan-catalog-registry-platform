================================================================================
NOTES
================================================================================

1. Search Request Context:
   - action = "search"
   - BAP provides: bap_id, bap_uri
   - BPP fields (bpp_id, bpp_uri) are not required in request

2. On_Search Response Context:
   - action = "on_search"
   - BPP adds: bpp_id, bpp_uri
   - New message_id generated for response
   - transaction_id remains same as request

3. Search Logic:
   - Filters: Active products, Active providers, Active offerings
   - Search query matches: product name, category, provider name, provider code
   - Empty intent returns all matching products

4. Response Structure:
   - Providers array groups items by provider
   - Same product can appear under multiple providers
   - Each item has unique listing_id (provider + product)
   - Tags contain: product_id (master), sku (provider), availability

5. Identifiers:
   - product_id: Master product ID (e.g., OAN-PROD-1001)
   - sku: Provider's SKU (e.g., ABC-NPK-001)
   - listing_id: Unique offering ID (e.g., LIST-ABC-001)
   - provider id: Provider code (e.g., ABC-AGRI-001)
